## Logic Notation

Logic notation is a way of writing down arguments into more formal statements. For example, if I argued that if it rained enough, the grass would be green, I could write this as if R then G or even simpler R → G (with R meaning it has rained and G meaning the grass is green). Therefore, through this notation, I have boiled down a sentence into 3 symbols.

## Liebniz 

Liebniz was infatuated by these ideas, he even took it as far as to say that If we were to have a form of perfect logic notation, then we would have world peace. He justified this by saying we would be able to write arguments in logic notation, and then evaluate the weight of different arguments mathematically. He called this system Calculus Ratiocinator.<br>
